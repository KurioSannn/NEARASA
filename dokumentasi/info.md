# Dokumentasi Proyek NEARASA

Folder ini berisi rekam jejak, catatan hasil kodingan, dan rincian per eksekusi teknis pengembangan fitur repositori NEARASA sesuai alur kerja baku.

## Struktur Folder:
- `H1/`: Catatan eksekusi Tahap 1 (TECH 1) - Optimasi backend controller & data efficiency dashboard pemilik.
- `H2/`: Catatan eksekusi Tahap 2 (TECH 2) - Redesign UI/UX Dashboard Pemilik mengadopsi visual terracotta & modular components.
- `H3/`: Catatan eksekusi Tahap 3 (TECH 3) - Pengujian menyeluruh, responsive checking, dan staging final.
