# Komponen Kalender Penjadwalan Pos & Tanggal Khusus (`PostScheduleCalendar.tsx`)

Folder ini berisi komponen kalender interaktif untuk manajemen jadwal harian, penentuan lokasi pos gerai, dan jam khusus (*special hours / holiday exceptions*) per tanggal di Ruang Pemilik NEARASA.

## File di dalam folder:
- `PostScheduleCalendar.tsx`: Komponen grid kalender bulanan (7 hari: Sen-Min), navigasi bulan, indikator status pos per tanggal (grid kompak berindikator titik pada layar seluler dan detail jam penuh pada desktop), serta modal pengaturan jam operasional atau status libur per tanggal.
- `info.md`: Dokumentasi konteks dan kegunaan komponen di folder ini.
